# item

[← Gateway](README.md)

Base `{BASE}` (`REACT_APP_BASE_URL`, the gateway); paths relative to `/api/v1/admin`. Case: reads snake_case (collections also camelCase fallbacks); writes mixed, product top level snake, nested variants/images camelCase, collections camelCase. Money: integer paise on every write (numbers; `PUT /variants/:id` and filter/rule `value`s as strings); reads typed `string`, screens convert paise → rupees. Store scoping: `?storeId=` query (`bulk-edit` puts it in the path; bulk bodies also carry `storeId`). Envelope: varies per endpoint, shown per row as the body gk-pages reads.

Client: bare `makeAPICall` unless noted. Merchant headers are added only by the `makeApiCall` wrapper (collections, variant list/update, vendors/types) or by hand on raw calls: product import (raw axios, `merchant-mid` only), export-data (raw `fetch`, both headers), create option (raw axios, no headers, no credentials).

- Images read as `src`/`alt`, written as `url`/`altText`.
- `PUT` sends variant-level `trackInventory` only for the `Default Title` variant; real variants are owned by `PUT /variants/:id`.

- `DraftOrder` reads `body.product ?? body.data.product`; everywhere else reads `body.product`.
- Keys `getStoreProducts` and `getProductsList` both build the list row; `searchProducts` / `searchAllProducts` are the two search rows.
