### Variants child

```ts
children: {
  variants: {
    path: 'variants',
    columns: [image, title, sku, price, stock],   // grouped by first option, groups collapsed
    editable: ['sku', 'price'],                   // saved variants only, as today
    preview: 4,                                   // design: "View all variants →"
    subRoute: '/products/$id/variants',
  },
}
```

- Options: preset names Size, Color, Material, Style, Weight; ≤ 3 options; combinations generated by the domain rule.
- New (unsaved) variants show a NEW badge and edit in a modal.
- Today's separate variant page (own save) becomes the variants sub-route inside the product draft; `product.save` sends variants with their stock per location (`inventory.warehouseQt`) in the same request, as today.

### Save

```ts
editor: { save: 'product.save', create: { route: '/products/new', command: 'product.create' } },
quickCreate: { fields: ['title', 'status', 'vendor'], command: 'product.create' },   // design
```

`product.save` → `PUT /products/:id` with `replaceVariants`, `replaceOptions`, `replaceOptionValues`; stock travels inside the same payload. Product-level SKU, price and inventory fields in today's payload are written from the default variant by the transformer.

### Validation (from `ProductForm.tsx`)

| Rule | Source |
|---|---|
| Title required | `:91` |
| Status in active/draft/archived | `:90-235` |
| Weight unit in kg/g/lb/oz | `:131` |
| Each option has ≥ 1 value | `:141` |
| Variant price required | `:150` |
| Variant SKU required | `:157`, `:1278` |
| Product SKU required when no variants | `:1272` |
| Image source required | `:214` |
| Custom field errors block save | `:1262` |
| Tags ≤ 50 chars | `ProductOrganization.tsx:517` |

No price vs compare-at check (none today).

### Derived values (from `utils/calculationFunctions.ts:2-12`)

- `profit = price − cost`
- `margin = price ≤ 0 ? 0 : profit / price × 100`, 2 decimals
